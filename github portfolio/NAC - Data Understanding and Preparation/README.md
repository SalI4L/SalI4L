# Project README

## 📌 Project Title  
**AI and Data Ownership in Sports: Ethical and Practical Implications**

## 📖 Overview  
This project examines the ethical and technical aspects of **data ownership in sports**, particularly in football. It combines data analysis, machine learning experimentation, and an ethics study to explore how player data is collected, used, and owned by different stakeholders.  

The project deliverables include:  
- A **Jupyter Notebook** with data processing, analysis, and modeling.  
- An **Ethics Report** discussing the debate over player vs. club data ownership.  
- A **final dataset and outputs** for reproducibility.  

---

## 🎯 Objectives  
1. Explore **ownership and control** of football player data.  
2. Analyze a **real dataset** for insights into player performance and club usage.  
3. Investigate **ethical implications** of AI and data analytics in sports.  
4. Propose **balanced frameworks** (e.g., shared ownership models) to protect both clubs’ investments and players’ rights.

## 🧩 Key Findings  

- **Players’ Rights**  
  - Data reflects personal effort, skills, and health.  
  - Enables contract negotiations, endorsements, and personal branding.  

- **Clubs’ Interests**  
  - Clubs invest in development, training, and infrastructure.  
  - Data supports scouting, performance tracking, and transfers.  
  - Contracts often give clubs ownership of collected data.  

- **Balanced Approach**  
  - Shared ownership model: players own personal/biometric data, clubs retain team-level analytics.  
  - Licensing and revenue-sharing agreements can create fairness.
